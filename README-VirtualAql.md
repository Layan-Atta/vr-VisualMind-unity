
# 🧠 Virtual Aql – Immersive Educational VR Environment

**Virtual Aql** is an immersive educational environment built using Unity and designed to run on VR headsets. The goal is to create a futuristic learning experience that engages students beyond traditional methods, by transporting them into a fully interactive virtual classroom.

🎯 **Objective:**  
Redefine how students interact with educational content using immersive VR simulations that enhance focus, memory, and understanding.

🧑‍🎓 **Target Audience:**  
Middle school to university students — especially in STEM fields — looking for deeper, distraction-free, and innovative learning experiences.

## 🌐 Project Vision

Virtual Aql is not just a demo — it’s a prototype of a scalable digital ecosystem for future learning. Think of it as a *smart classroom inside a headset*, offering:

- Simulated environments for focused study
- Interactive elements to trigger memory and engagement
- Peaceful, minimal distraction designs
- Space for deep work, self-reflection, or guided learning

## 🛠️ How to Run the Project (Unity VR)

1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/virtual-aql-vr.git
   ```
2. Open the project in Unity Hub (tested on Unity 2021.3+ with XR Plugin Management enabled).
3. Make sure the Oculus Integration or OpenXR is installed and configured.
4. Open the scene `VirtualAql_Main.unity`.
5. Connect your VR headset (e.g., Oculus Quest via Link).
6. Enter Play Mode or build the project to your VR device.
